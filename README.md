# ארנה — משחק סיטואציות

הכיתה שלך נשאבת מאמצע שיעור היסטוריה לעולם אחר, אל עיר מרחפת בשם **אורדן**, ומכאן כולכם לוחמים בזירה. זה משחק סיפור שבו כל בחירה משנה את ההמשך.

## איך משחקים

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

### שמירה

- **שמירה אוטומטית** אחרי כל בחירה וכל תור בקרב. אחרי רענון הדף אפשר להמשיך מאותה נקודה, גם באמצע קרב.
- **נקודות שמירה אוטומטיות** בתחילת כל פרק ולפני כל קרב (12 האחרונות), כדי לחזור אחורה ולנסות אחרת.
- **3 משבצות שמירה ידניות.**
- **קוד שמירה**: אפשר להעתיק קוד או להוריד קובץ, ולטעון אותו במכשיר או בדפדפן אחר.
- אם הדפדפן חוסם שמירה (דפדפן בתוך וואטסאפ/אינסטגרם, או גלישה בסתר), המשחק מציג אזהרה.

הכול נמצא בחלון 💾. גם הסופים שגילית נשמרים.

## מה יש במשחק

- **כוחות מתעוררים**: בקרב הראשון בוחרים איזה כוח מתעורר בך (להבת הזעם, הליכת צל, חומת האור או קול הפקודה). הכוח מתחזק לאורך הסיפור.
- **קבוצה שמתפרקת**: הקבוצה מתחילה עם חמישה לוחמים. בסוף העונה הראשונה לורד ורקס קונה שלושה מהם, ונשארים שניים. אפשר לנסות להציל אחד, לגייס לוחמים חדשים, ובהמשך אולי להחזיר את החברים.
- **החלטה בסוף כל עונה**: להמשיך להילחם בארנה, להפוך למשרת באחד הבתים הגדולים, או לנסות לברוח דרך שער השבר ולחזור הביתה.
- **אמון**: לכל חבר בקבוצה יש רמת אמון שמשפיעה על מה שיקרה איתו בהמשך.
- **קרבות בתורות**: כל קרב בזירה נמשך עד 6 תורות. בכל תור רואים מה היריב מתכוון לעשות, ובוחרים: התקפה, כוח, התגוננות, פקודה לחבר בקבוצה, פריט או כניעה. יומן הקרב מציג כל הטלת קוביות.
- **זהב לפי השפעה**: הפרס על כל קרב מתחלק לפי ההשפעה שלך — הנזק שעשית, ההגנה על הקבוצה והפקודות — מול מה שהקבוצה עשתה.
- **הנשקייה**: קונים נשק, שריון, קמעות ופריטים מתכלים בזהב מהקרבות (כפתור 🛡️).
- **לוחמים עם יכולות**: זיו (מהירות), איריס (תעופה), רנה (שינוי צורה), גורן ויואב (כשפי אדמה). יש להם יכולות בקרב, ויש גם יריבים עם אותן יכולות.
- **פירוט סיכון**: לכל בחירה עם קוביות או קרב יש כפתור "📊 פירוט הסיכון" — מה צריך להטיל, מה הסיכוי, ומה יקרה בהצלחה ובכישלון. לקרבות מוצגת הערכת סיכוי לפי 300 קרבות מדומים.
- **שלוש עונות**: עונה 1 (הנשאבים), עונה 2 (ליגת הדם / הקולר), ועונה 3 — ליל שלושת הירחים: התנקשות בלילה, חצי הגמר האחרון מול בית ורקס, ושומר הלב, יצור קריסטל ששותה כוחות. המנצח מקבל את המשאלה.
- **13 סופים שונים**: חזרה הביתה, כל הכיתה חוזרת, השבר הגדול, הכרוז החדש, המשאלה, האגדה של אורדן, הלוחם הנצחי, מוות בזירה, בור העבדים, וארבעה סופים של מסלול המשרת.

## מבנה הקבצים

| קובץ | תוכן |
|---|---|
| `js/core.js` | מנוע: מצב המשחק, קוביות, מעבר בין סצנות, פנייה לפי מגדר |
| `js/battle.js` | קרבות: ציוד, יריבים, יכולות, תורות, פרס לפי השפעה |
| `js/story.js` | פרולוג ועונה 1 |
| `js/story2.js` | סוף עונה, עונה 2 (ארנה / משרת), בריחה |
| `js/story3.js` | עונה 3 — הגמר הגדול, והסופים שלה |
| `js/endings.js` | סופי הבריחה, המוות ומסלול המשרת |
| `js/saves.js` | שמירה: אוטומטית, נקודות שמירה, משבצות וקוד שמירה |
| `js/ui.js` | ממשק |
| `tools/simulate.js` | בדיקה אוטומטית |

### כתיבת סצנות

```js
scene('my_scene', {
  title: 'כותרת',
  chapter: 'עונה 1',
  text: (s) => `טקסט. {אתה נכנס|את נכנסת} לחדר, $name.`,
  choices: [
    { text: 'בחירה רגילה', effect: (s) => addStat(s, 'power', 1), next: 'other_scene' },
    { text: 'קרב', battle: 'sandwolf', win: 'win_scene', lose: 'lose_scene' },
    {
      text: 'בחירה עם קוביות',
      check: { stat: 'agility', dc: 12, team: true },
      success: 'win_scene',
      fail: 'lose_scene',
    },
  ],
});
```

`{זכר|נקבה}` מתחלף לפי מגדר השחקן, ו-`$name` מתחלף בשם.

### בדיקה

```
node tools/simulate.js 5000
```

הסקריפט בודק שאין קישורים שבורים ומריץ אלפי משחקים אקראיים. הוא מדווח על שגיאות, על סימוני מגדר שלא הוחלפו, ועל הסופים שהושגו.
