# ארנה — משחק סיטואציות

הכיתה שלך נשאבת מאמצע שיעור היסטוריה לעולם אחר, אל עיר מרחפת בשם **אורדן**, ומכאן כולכם לוחמים בזירה. זה משחק סיפור שבו כל בחירה משנה את ההמשך.

## איך משחקים

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

המשחק נשמר אוטומטית בדפדפן, וגם הסופים שגילית נשמרים.

## מה יש במשחק

- **כוחות מתעוררים**: בקרב הראשון בוחרים איזה כוח מתעורר בך (להבת הזעם, הליכת צל, חומת האור או קול הפקודה). הכוח מתחזק לאורך הסיפור.
- **קבוצה שמתפרקת**: הקבוצה מתחילה עם חמישה לוחמים. בסוף העונה הראשונה לורד ורקס קונה שלושה מהם, ונשארים שניים. אפשר לנסות להציל אחד, לגייס לוחמים חדשים, ובהמשך אולי להחזיר את החברים.
- **החלטה בסוף כל עונה**: להמשיך להילחם בארנה, להפוך למשרת באחד הבתים הגדולים, או לנסות לברוח דרך שער השבר ולחזור הביתה.
- **אמון**: לכל חבר בקבוצה יש רמת אמון שמשפיעה על מה שיקרה איתו בהמשך.
- **קוביות**: בחירות מסוכנות מוכרעות בהטלת קוביות, יחד עם התכונות שלך, הכוח והקבוצה. על כל כפתור מוצג סיכוי ההצלחה.
- **עונות 1 ו־2 כתובות** (עונה 3 בדרך — מי שבוחר להמשיך להילחם אחרי עונה 2 מגיע למסך "המשך יבוא").
- **8 סופים שונים** בינתיים: חזרה הביתה, כל הכיתה חוזרת, מוות בזירה, בור העבדים, וארבעה סופים של מסלול המשרת.

## מבנה הקבצים

| קובץ | תוכן |
|---|---|
| `js/core.js` | מנוע: מצב המשחק, קוביות, מעבר בין סצנות, פנייה לפי מגדר |
| `js/story.js` | פרולוג ועונה 1 |
| `js/story2.js` | סוף עונה, עונה 2 (ארנה / משרת), בריחה |
| `js/endings.js` | הסופים ומסך "המשך יבוא" לעונה 3 |
| `js/ui.js` | ממשק |
| `tools/simulate.js` | בדיקה אוטומטית |

### כתיבת סצנות

```js
scene('my_scene', {
  title: 'כותרת',
  chapter: 'עונה 1',
  text: (s) => `טקסט. {אתה נכנס|את נכנסת} לחדר, $name.`,
  choices: [
    { text: 'בחירה רגילה', effect: (s) => addStat(s, 'power', 1), next: 'other_scene' },
    {
      text: 'בחירה עם קוביות',
      check: { stat: 'agility', dc: 12, team: true },
      success: 'win_scene',
      fail: 'lose_scene',
    },
  ],
});
```

`{זכר|נקבה}` מתחלף לפי מגדר השחקן, ו-`$name` מתחלף בשם.

### בדיקה

```
node tools/simulate.js 5000
```

הסקריפט בודק שאין קישורים שבורים ומריץ אלפי משחקים אקראיים. הוא מדווח על שגיאות, על סימוני מגדר שלא הוחלפו, ועל הסופים שהושגו.
